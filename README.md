# Java · Une API de commande fiable — élève

**4 h 30 · Java / API · PilotCrew.** Construire une API Java qui valide une commande fictive, calcule son montant et expose des erreurs vérifiables.

L’atelier évalue une petite API explicable et reproductible. Il ouvre le fil rouge ; aucun paiement n’existe encore.

Ce support contient les tutoriels, mémos et espaces de réponse. Créer le code demandé dans `backend/` et `frontend/` ; le corrigé est privé et séparé. Les six séances forment un fil rouge progressif de **27 heures**, sans promesse de niveau senior.

## Préparer la séance

Aucun acquis de code à importer ; le lab commence avec les consignes et les outils prêts.

## Démonstration fictive

Aucune carte, aucun argent réel, aucune donnée personnelle, aucun compte ni identifiant PSP. L’écran garde une mention de démonstration ; les montants et états font autorité côté serveur. La mémoire est effacée au redémarrage.
